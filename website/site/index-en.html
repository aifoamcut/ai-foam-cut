Free software for CNC hot-wire cutters

From wings to complex shapes – everything in one software

AI Foam Cut covers the whole chain: design the wing, derive a core or negative shell, compensate for kerf and sheeting, generate G-code, simulate it in 3D and send it to the machine straight from the program. The machine control is compatible with grblHAL and GRBL HotWire Mega 5X – matching information and firmware for the boards are available from RC Keith.

The program is open source and free of charge – released under the GNU General Public License 3.0. No licence keys, no trial periods, no features behind a paywall, no telemetry. Take the ready-made Windows build, or the source code if you would rather look inside and build it yourself.

How it works

Wings

Every change in the design immediately affects drawing, cutting path and G-code.

Free contours and 3D models

Everything that is not a wing: fuselages, tail surfaces, formers, lettering, panels from CAD.

Via DXF shapes

  1. Load DXF or SVG; every layer is offered as a profile.
  2. Check the rib chain, assign layers per segment as INNER and OUTER and align them.
  3. Block geometry: segment width, block dimensions, minimum clearance.
  4. Set sync points when INNER and OUTER differ.
  5. Choose direction, kerf and safe lead-in/lead-out, then G-code and cut.

No DXF file? “Draw freely” opens the built-in CAD editor; the result goes straight back into DXF shapes.

Via the 3D model

  1. Load an STL model.
  2. Choose the cutting axis, distribute planes evenly or place them individually, split.
  3. Per cross-section set kerf, feed rate, lead-in point and direction; start point by clicking on the path.
  4. Use as G-code source or nest several cross-sections of equal thickness as a plate from one block.
  5. Simulate, cut, glue the cross-sections together and sand.

Wing tips, winglets and mould making

The same wing becomes a plug or a negative mould – as STL for 3D printing and CNC milling, as STEP for CAD.

Wing tip and winglet

  1. Wing tip: leading and trailing edge lines run as superellipses to the reference point. Templates modelled on real sailplanes (elliptic, crescent, raked, upswept), then length, upsweep, washout and thickness distribution freely adjustable.
  2. Winglet with tangential transition arc: length, cant, sweep, toe-out, twist, own airfoils for root, middle and tip.
  3. Winglet from drawing: sketch the shape in the three-view editor, the software builds the transition.
  4. Export wing and tip or winglet separately, matched via joiner holes.

Mould making

  1. Choose the target: plug (positive), split plug for moulding, or both negative mould halves.
  2. All ribs are smoothed as B-splines; allowance for paint/gelcoat and trailing-edge thickness adjustable globally.
  3. Parting surface follows the chord surface; margins, dowel holes, joiner recesses and resin groove in the flange.
  4. Segment large moulds into printable pieces; curvature and zebra analysis for surface checks.
  5. Export as STL (Z up, ready to print and mill) or as STEP solid for Fusion, SolidWorks, FreeCAD.

Project overview & material database

  • Create and name a project
  • Set the number of wings
  • Assign design (core/negative) and material to each wing
  • Create materials freely: name, density, category
  • Calibrate kerf and heating values per material
  • Export and import material data
  • Weight estimate per wing (core, sheeting, cloth, resin)

Wing design

  • Load airfoils as .dat, DXF or .bez
  • Any number of segments, chords, span
  • Sweep, washout, dihedral, hinge position
  • Global sweep: keep leading edge, trailing edge or hinge straight
  • Airfoil height alignment (highest point, hinge, chord)
  • Sheeting deduction
  • Many types of spar and hinge cut-outs
  • Several wings per project

Core design

  • Block allowances and cut extensions per segment
  • Kerf compensation, selectable on upper/lower shell
  • Rotate workpiece (sweep) for an angled block position
  • Mirror and stack cores
  • Edit individual points

Negative-shell design

  • Mould halves
  • Core and support material in the same cut
  • Split the core into individual webs (glass sleeve, spar cap, web spacing)
  • Edit individual points

DXF shapes

  • Any contours from DXF or SVG
  • Assign layers freely to INNER and OUTER
  • Sync points for differing cross-sections
  • Draw freely in the CAD editor
  • Export and import GMFC projects (.cnc)

3D model

  • Load an STL model
  • Split into cross-sections, choose cutting axis and planes freely
  • Hot-wire G-code per cross-section
  • Plate mode: nest several cross-sections of equal thickness from one block
  • Move cross-sections and edit connecting paths

Mould making

  • Plug or both negative mould halves as STL
  • For 3D printing and CNC milling
  • Smoothed airfoils, adjustable wing tip and winglet
  • Parting surface and dowel holes
  • Segmentation into printable pieces

Rib designer

  • Ribs and half ribs from the wing
  • Sheeting and spars taken into account
  • Leading-edge templates as sanding aids
  • Export as STL or DXF

CAD editing

  • Built-in 2D CAD editor
  • Background image as template
  • Import from all designs
  • Send the result to DXF shapes

Machine

  • Machine control via Web Serial (grblHAL, Mega 5X)
  • Jogging, homing, wire heating
  • $$ settings editor for the controller

Requirements

A Windows PC for the ready-made .exe; from source it runs anywhere with Python 3.11 or newer. The interface runs in a browser (Chrome or Edge), the machine connection uses Web Serial.

Controllers

grblHAL with four axes (e.g. BTT SKR Pico) or Mega 5X (GRBL HotWire Mega 5X). Axis names freely configurable. Matching information and firmware for the boards are available from RC Keith.

File formats

Airfoils .dat, DXF, SVG · Models STL, OBJ, 3MF · Export G-code, DXF, STL, GMFC .cnc · Projects as JSON.

Operation

Starts as a single .exe with a local server, or straight from source with python launcher.py. No installation, no internet connection, no registration. Data stays on your own computer.

Build and modify it

  • A plain web application with a small Python server, no build step required
  • Ready to run with python launcher.py (Python 3.11 or newer)
